# さんいん手帖 京都（静的サイト）

出産費用の無償化にそなえて、京都府の産院を「じぶんで払う部分」（個室・無痛分娩・お祝い膳・産後ケア）でくらべるサイトです。

公開先：https://sanin-techo.jp （GitHub Pages：main ブランチの /docs）

## 作り方（ビルド）

```
python3 build.py   # docs/ にサイトができます
```

## ファイルの場所

- `build.py`：ページを作るプログラム。上のほうの `CONFIG` で、ドメイン・AmazonのトラッキングID・お問い合わせ先・所在地を設定します。
- `data/`：産院のデータ（地域ごとのJSON）。直したら `python3 build.py` をもう一度実行します。
- `content/`：記事。`===id|タイトル|日付|pr` で1本ずつ区切ります（`pr` は紹介料つきの記事）。
- `static/`：見た目（site_style.css）、ロゴ、イラスト。
- `docs/`：できあがったサイト（GitHub Pages で公開される場所）。直接は直さず、build.py で作りなおします。CNAME もここに自動で入ります。

## 決まりごと

- ランキング・口コミ・おすすめはのせない（医療広告ガイドライン）。ならび順は地域ごと。
- 紹介料のある記事は、記事の上に【広告】、一覧に「PR」、Amazonの決まった一文を表示（ステマ規制）。
- 産院の情報には、出どころと調べた日をかならず書く。
